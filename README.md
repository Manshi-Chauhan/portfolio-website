# 💻 Manshi Chauhan — Developer Portfolio Website

A sleek, responsive, and modern personal portfolio website built with clean **HTML5**, **CSS3**, and vanilla **JavaScript**. Inspired by GitHub's dark mode developer aesthetic with subtle glowing accents and interactive elements.

## 🌟 Key Features

- 🖤 **GitHub Dark Developer UI:** Styled with authentic GitHub dark canvas tones (`#0d1117`, `#161b22`, `#21262d`) and glowing electric blue/purple/green accents.
- 📱 **Fully Responsive Design:** Clean mobile-first layout with smooth hamburger drawer navigation and adaptive layouts across all screen resolutions.
- ⌨️ **Dynamic Typewriter Animation:** Rotating developer roles highlighting Python development, AI/ML engineering, and tech writing.
- 📂 **Interactive Project Showcase:** Categorized project filtering (*All, Python & GUI, Web & APIs, Data Analytics*) with direct GitHub repository links.
- 📜 **Education & Certifications Timeline:** Highlighted B.Tech in CSE (AIML) at AKTU (SGPA 8.3) and certifications from Columbia University, IBM, and upSkill.
- 📋 **1-Click Copy & Toast Alerts:** Instant email copy-to-clipboard with smooth toast notifications.
- ⚡ **Zero External Heavy Frameworks:** Pure vanilla HTML/CSS/JS for ultra-fast loading speed and zero dependency overhead.

## 🚀 Getting Started Locally

You can run this project locally without any dependencies:

### 1. Clone the repository
```bash
git clone https://github.com/Manshi-Chauhan/portfolio-website.git
cd portfolio-website
```

### 2. Open in your browser
Simply open `index.html` in your favorite web browser:
```bash
# Windows
start index.html

# Or run with Python local server
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
